# Form & Field

A considered collection of everyday objects, built as a responsive React shopping cart application.

## Development

Requires Node.js 22.12 or newer.

```sh
npm install
npm run dev
```

## Project milestones

- [x] React and Vite foundation
- [ ] Editorial storefront and searchable product catalog
- [ ] Persistent cart, product details, and order review
- [ ] Responsive and accessibility verification, automated tests, and documentation

The project uses the shopping flow of the [assignment reference](https://startling-beijinho-72802b.netlify.app/) with an original homewares brand and visual design.
